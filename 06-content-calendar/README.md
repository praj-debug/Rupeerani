# Content Calendar and Production

Use this folder for the publishing calendar, scripts, production deadlines, asset references and post-publication reviews.

## Workflow states

`IDEA → RESEARCH → SCRIPT → REVIEW → READY → PRODUCING → SCHEDULED → PUBLISHED → REVIEWED`

Keep a single source of truth for deadlines and status. Do not count a draft as published work.

## Suggested folder layout

```text
06-content-calendar/
├── README.md
├── calendar.csv
├── templates/
│   ├── short-video-brief.md
│   ├── long-video-brief.md
│   └── post-publication-review.md
└── scripts/
    └── YYYY-MM/
```

## Calendar fields

- Content ID
- Planned publish date
- Platform
- Pillar
- Working title
- Format
- Language
- Source and fact-check status
- Script due date
- Production due date
- Review owner
- Status
- Published URL
- Performance review date

## Production checklist

- [ ] Audience question chosen
- [ ] Research and source notes captured
- [ ] Script reviewed
- [ ] Recording or design completed
- [ ] Captions and accessibility checked
- [ ] Final factual review complete
- [ ] Thumbnail, title and description checked
- [ ] Publication link recorded
- [ ] Metrics review scheduled

## Starter calendar

No future post is represented as committed until a date and production capacity are confirmed. Create `calendar.csv` once the next publishing window is planned.
