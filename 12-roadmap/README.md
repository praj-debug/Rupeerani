# Roadmap

This is a working roadmap, not a claim that tasks are completed. Update status and dates as capacity, evidence and dependencies become clear.

## Phase 1: Foundation

- [ ] Write the founder story and record genuine milestones.
- [ ] Finalise a clear first audience segment and priority problem.
- [ ] Review vision, mission, values and positioning.
- [ ] Define source, correction, disclosure and editorial standards.
- [ ] Gather and approve founder and brand assets.

## Phase 2: Research and identity

- [ ] Conduct initial audience conversations.
- [ ] Synthesize needs, questions and competing alternatives.
- [ ] Approve visual identity and messaging guidelines.
- [ ] Confirm the roles of StockRani, StockRani Decodes and StockRani Studio.

## Phase 3: Content system

- [ ] Choose priority content pillars.
- [ ] Establish a realistic production cadence.
- [ ] Publish a small first batch and record source notes.
- [ ] Set baseline metrics and review dates.
- [ ] Create a monthly learning review.

## Phase 4: Website and audience experience

- [ ] Define site navigation and first useful visitor task.
- [ ] Publish founder and editorial standards pages.
- [ ] Publish a small set of carefully reviewed evergreen resources.
- [ ] Validate usability, accessibility, mobile layout and links.

## Phase 5: Growth and sustainability

- [ ] Run documented experiments against a baseline.
- [ ] Improve the content system using evidence.
- [ ] Validate demand before building paid resources.
- [ ] Evaluate commercial partnerships against trust and disclosure rules.
- [ ] Review workload and keep the scope sustainable.

## 30 / 60 / 90-day planning

| Horizon | One priority outcome | Evidence of completion | Dependencies |
|---|---|---|---|
| First 30 days | Establish a clear foundation and starting baseline | Reviewed docs and research notes | Founder time and access to audience |
| By 60 days | Test a repeatable content workflow | Published batch and review notes | Production capacity and source review |
| By 90 days | Use evidence to select the next direction | Experiment results and updated priorities | Sufficient observation period |

Choose specific dates after confirming the project start point and weekly capacity.
