# Brand Assets

Store approved assets that are suitable for a public repository.

## Asset inventory

- RupeeRani logo files and social avatars.
- Colour, typography and brand guideline files.
- Approved StockRani identity assets.
- Approved founder portrait, when selected for publication.

## Asset rules

- Use an authentic, approved founder photo if publishing a founder portrait.
- Confirm rights and permissions before committing any asset.
- Strip unnecessary location and personal metadata from public images.
- Avoid committing private documents, source files with personal data, passwords, API keys or account details.
- Use descriptive filenames and record version or approval status.
